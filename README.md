# TC264 疯狂电路组智能车

本项目面向第二十一届全国大学生智能汽车竞赛疯狂电路组，
基于英飞凌 TC264 微控制器，采用摄像头视觉寻迹与负压吸附方案，
实现电路图赛道中的边界提取、道路状态识别、路口处理和车辆运动控制。

## 图像处理

图像处理采用传统视觉算法，主要流程包括：

1. 使用大津法（Otsu）计算阈值，对摄像头图像进行二值化。
2. 使用八邻域爬线算法提取赛道左右边界。
3. 分析边界丢失情况、拐点和道路连通特征，判断直道、弯道及分岔路口。
4. 针对不同道路状态进行补线和中线构建，为转向控制提供图像偏差。
5. 结合状态机处理路口转向、普通弯道及部分元器件图案造成的断线干扰。

## 运动控制

车辆采用方向外环与左右轮速度内环组成的双层控制结构：

- **方向外环**：采用非线性 PD 控制，并加入陀螺仪 Z 轴角速度反馈，
  根据图像偏差计算左右轮的目标速度差。
- **速度内环**：左右轮分别采用编码器速度反馈和增量式 PI 控制，
  并叠加速度前馈，计算电机 PWM 输出。
- **辅助处理**：包含速度滤波、启动速度斜坡和输出限幅。

控制流程：

图像偏差 → 转向控制 → 左右轮目标速度
                         ↓
                  编码器速度反馈
                         ↓
                  增量式 PI＋前馈
                         ↓
                    电机 PWM

## 主要代码

| 文件 | 主要作用 |
|---|---|
| `code/go.c` | 图像处理流程与道路状态处理入口 |
| `code/deal_image.c` | 边界搜索、特征提取、补线及道路状态机 |
| `code/pid.c` | 转向外环、左右轮速度内环及速度前馈 |
| `code/gyro.c` | 陀螺仪数据处理 |
| `code/encoder.c` | 编码器接口 |
| `code/motor.c` | 电机与负压控制接口 |
| `user/cpu0_main.c` | 系统初始化与调试任务 |
| `user/cpu1_main.c` | 图像与控制任务入口 |
| `user/isr.c` | 定时中断与速度环调度 |
